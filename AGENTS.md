# AGENTS.md

Guidance for agents working in this repo.

## Project

PlayerMenu (player menu plugin for Spigot/Folia). Single Maven module: `newgen` (PlayerMenuNG), Java 17, built with `mvn clean package` from the repo root or `cd newgen && mvn clean package`.

Key docs: [docs/README.md](docs/README.md) is the index; [ARCHITECTURE.md](docs/ARCHITECTURE.md) and [DEVELOPMENT.md](docs/DEVELOPMENT.md) describe the current implementation.
